# Openrouter App

We can advertise Ylva on Openrouter by sending dedicated headers
on requests, see [App Attribution](https://openrouter.ai/docs/app-attribution).

- `HTTP-Referer: https://github.com/manuel-koch/ylva`
- `X-OpenRouter-Title: Ylva`
- `X-OpenRouter-Categories: cli-agent,personal-agent`

Only use these headers once Ylva is publicly available at
Github !
